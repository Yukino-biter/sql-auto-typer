# SQL 逐字输入扩展

已确认范围：Chrome / Edge，普通网页输入框及编辑器，主要使用头歌。暂不包含 VNC 远程桌面。

实现顺序：
- 字符切分与输入队列：保留 SQL 空白、中文、Emoji；测试暂停、停止、失败和并发。
- MV3 后台：debugger Input.insertText 逐字提交，所有换行与 Tab 均为文本，不发送执行快捷键。
- 目标守卫：绑定输入元素，监测焦点、内容、光标、标签页和页面导航；异常暂停。
- 弹窗：文本、速度、倒计时、进度、控制按钮及快捷键；只保存设置，不保存 SQL。
- 浏览器实测：禁止粘贴 textarea、contenteditable、CodeMirror、Monaco，中文、缩进、引号、换行及中断恢复。
- 交付：可加载的扩展文件夹、ZIP、安装文档和测试记录。

每次输入前检查目标，原生输入框和可读取模型的编辑器每次输入后对照内容。读取不了模型的编辑器不宣称已验证内容。头歌登录后实训页面需要用户本机复核。

交付状态：上述功能已实现。1.0.1 增加头歌组件内 Monaco 实例适配和浏览器命令超时。9 项核心测试通过；浏览器测试和真实页面验证分别见 test-results-chromium.md、test-results-edge.md 和 educoder-verification.md。
